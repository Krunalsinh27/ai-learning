# House Price Prediction

## About the Project

This is a Machine Learning project to predict house
selling prices using the Kaggle House Prices dataset.

## Current Progress

- Loaded the training and testing datasets
- Explored the dataset structure and columns
- Identified the target variable: SalePrice
- Explored important house features
- Checked data types and missing values
- Investigated the meaning of missing values
- Started analyzing missing masonry veneer values

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

Download the dataset from Kaggle:

https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

Extract the downloaded ZIP file into a folder named `data`.
