# Seaborn for Statistical Data Visualization

A comprehensive collection of **Seaborn** concepts, examples, and hands-on practice notebooks. This repository covers the most commonly used statistical visualizations for Exploratory Data Analysis (EDA), Machine Learning, and Data Science.

---

## About

Seaborn is a high-level Python data visualization library built on top of Matplotlib. It provides attractive statistical graphics with less code and is widely used for Exploratory Data Analysis (EDA).

This repository documents my learning journey through Seaborn with practical examples, customization techniques, and real datasets.
